🔐 Vault Pocket

A secure, cross-platform mobile password manager built with React Native.

Vault Pocket is a mobile application designed to provide users with a secure and convenient way to store, manage, and generate complex passwords.

The application combines secure authentication, encrypted credential storage, password generation, multi-factor authentication, and real-time synchronization to help users manage their digital credentials from one place.

✨ Features

🔑 Secure Authentication — User registration and login with Firebase Authentication

🔒 Encrypted Storage — Sensitive password data is protected using AES encryption

🎲 Password Generator — Generate strong and complex passwords

🛡️ Multi-Factor Authentication — Additional security layer for user accounts

☁️ Real-Time Synchronization — Keep password records synchronized across supported devices

📱 Cross-Platform — Built with React Native for mobile platforms

👤 User-Specific Data — Each user's records are associated with their unique account

🔍 Security Testing — Tested through penetration testing, code analysis, and resilience testing
